# Enterprise GIS AI Assistant — a working demo

Your enterprise GIS questions, answered in seconds, with sources. This is a working AI assistant demo by Janaki Gattu: ask it about ArcGIS Enterprise migration, ArcGIS Online migration, AI Assistants in ArcGIS, ArcGIS Monitor, or what it takes to run an AI agent in production, and it answers from a knowledge base built from her published LinkedIn articles and Esri's public documentation. Or run the guided Migration Readiness check: eight questions, a score out of 100, a recommended approach, and the gaps to close before you commit.

## How to run it

Open `index.html` in any modern browser. There is nothing to install and nothing to configure.

## What is inside

- **Ask the assistant** — a chat interface with suggested questions. It matches your question against a knowledge base of real answers drawn from Janaki's articles (Migration, Utility Network, Harness Engineering) and Esri documentation (AI Assistants, ArcGIS Monitor, distributed collaboration). Every answer names its source and ends with a next step.
- **Migration Readiness check** — the eight questions from Janaki's migration article, answered one at a time, producing a readiness score, a band (ready, nearly ready, or not ready yet), a recommended approach (WebGISDR, Join Site, distributed collaboration, group export and import, scripting, or rebuild), and a list of gaps to close.
- **Honest by design** — the page says plainly that the demo runs entirely in the browser with no server and no API key. It is a working demonstration of the kind of assistant Janaki builds for GIS teams, not a model connected to the internet.
