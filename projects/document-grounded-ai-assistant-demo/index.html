Document-Grounded AI Assistant

An AI assistant is only as trustworthy as the documents it answers from. Ask a question and watch it answer from the documents, with the source shown for every line.

How this demo works, honestly: it runs entirely in your browser. There is no server, no API key, no account, and nothing you type leaves this page. The three document sets below are samples written for this demo. A production version connects to your team’s real documents and answers from those instead. When no document covers your question, this demo says so, instead of guessing.

How it works, in plain language

Step 1

Cut the documents into passages

Each document is split into short passages, one subject each, so the assistant retrieves a precise answer instead of a whole manual.

Step 2

Index what each passage covers

Each passage is indexed by its subject and keywords, so a question about response times finds the response time passage and not the patching one.

Step 3

Retrieve, then answer

Your question is matched against the index. Only the passages that match are used, and the answer is built from those passages alone.

Step 4

Show the source

Every line of the answer carries a citation to the document and section it came from, so anyone can check it in seconds.

A production version adds three things this demo does not need: your real document store instead of samples, access control so staff only see what they are allowed to see, and a model that writes the answer in full sentences from the retrieved passages. The retrieval and the citations stay exactly as you see them here.
