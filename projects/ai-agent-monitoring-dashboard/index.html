What a production version adds

  1. Real telemetry, not sample data. Every run logged with its inputs, tool calls, retrieved passages, output, latency, and cost, the way the harness article requires full logging.
  2. Alerts, not just charts. A threshold per assistant: success below 95 percent, grounded answers below 90 percent, or cost above the daily ceiling pages the owner instead of waiting for someone to open the dashboard.
  3. A cost ceiling that bites. The daily cost ceiling from the harness stops new runs when it is hit, so a runaway loop cannot spend the month's budget in an afternoon.
  4. Groundedness checks on every answer. Each answer is checked against the passages it cites, and an answer with no source is flagged before it reaches the user.
  5. Access control and retention. Run logs hold real user questions, so they need the same access rules and retention limits as any other record with personal data in it.
