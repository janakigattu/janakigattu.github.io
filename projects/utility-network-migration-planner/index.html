Utility Network Migration Planner

A trace returns the wrong customers, and nobody notices until someone who knows the field checks it. Modernising to the Utility Network is a modelling decision, not a data move, so count what you have, run the four gates, and price the migration before a single feature moves. Enter your network below and this planner builds a phased migration plan with a person-day estimate, the flags that set the schedule, and a checklist you can print.

How this planner works, honestly: it runs entirely in your browser. There is no server, no API key, no account, and nothing you enter leaves this page. The migration rules come from Esri’s published Utility Network guidance and from Janaki’s article on modernising the model before migrating the data, checked 27 November 2026. The effort numbers are planning ranges from typical migration work, not a quote and not Esri’s numbers, so treat them as the size of the job, not the price of it.
