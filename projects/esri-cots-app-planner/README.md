# Esri COTS App Planner

Pick the wrong ArcGIS app and the build fails before it starts. This planner asks what the app has to do, who uses it, and what data you have, then tells you which standard Esri app to build, which widgets it needs, and how many days it takes.

## What it does

- Six jobs: show data on a map, search and filter records, numbers and charts for managers, tell a story with maps, collect data in the field, compare before and after.
- Recommends one COTS app: ArcGIS Experience Builder, ArcGIS Dashboards, ArcGIS StoryMaps, ArcGIS Field Maps, or ArcGIS Survey123, with the reasoning in plain words.
- Names the widgets to add, from Esri documentation: Experience Builder widgets (Map, Search, List, Filter, Query, Chart, Table, Swipe, Print, Survey, Basemap Gallery, Map Layers), Dashboard elements (Indicator, Gauge, Serial chart, Pie chart, List, Details, Embedded Content, Selectors), StoryMap blocks (Sidecar, Map tour, Swipe, Timeline).
- Scores readiness out of 100, prices the work in person-days with calendar weeks for one person and a team of two, lists the data prep steps, the gaps to close, five phases, and a printable ten-item checklist.
- Three presets: a public parcel viewer, an executive operations dashboard, and a field inspection crew.

## How it works

Everything runs in your browser. No backend, no API key, no account, and nothing you type is sent or stored anywhere. The widget names come from Esri documentation, linked on the page. The day estimates, readiness scores, and phase splits are planning rules from practice, stated on the page wherever they are used.
