ArcGIS Monitor Deployment Planner

Monitor only earns its keep when it watches the right things and tells the right people.

ArcGIS Monitor is Esri's monitoring for ArcGIS Enterprise: health, usage, and performance, with alerts when a metric crosses a threshold you set. This planner sizes the deployment, picks the components to register, and writes the first alert set. Nothing leaves your browser.

Honest note: this page runs entirely in your browser. There is no backend, no API key, and nothing is sent anywhere. The deployment shape and the component list come from Esri's published ArcGIS Monitor documentation. The alert thresholds are starting points from practice, not Esri numbers, and the page labels them as such: run a two-week baseline first, then tune them to your own numbers.
