# ArcGIS User Type and Licence Planner

Too many people on the wrong licence is the quietest line on an ArcGIS Online bill. Count your team by what they actually do, and this planner names the cheapest user type that covers each job, with the annual bill to prove it.

## What it does

Enter headcounts by job: executives who only view maps, field crew, data editors, map and app builders, GIS analysts, and advanced analysts. Answer the two questions that move people up a tier: how many viewers also edit data, and how many map builders need ArcGIS Pro Standard. Check the six editable rates, and press Plan my licences.

You get the annual bill by user type, the total headcount and credits included, the biggest cost driver named with its share, the two fixes that cut the bill fastest with the saving on each, the one-Creator minimum rule applied when your team has none, and a short checklist to run before you buy.

## The facts it stands on

- Six ArcGIS Online user types, with what each can and cannot do, from Esri's own documentation: Viewer (view only), Contributor (view and edit, no analysis, create, or share), Mobile Worker (field collection, no analysis, create, or share), Creator (create, analyse, administer, includes ArcGIS Pro Basic), Professional (everything in Creator plus ArcGIS Pro Standard), Professional Plus (everything in Professional plus ArcGIS Pro Advanced and the extensions).
- An organisation needs at least one Creator, Professional, or Professional Plus licence, and the organisation administrator needs Creator or higher.
- Rates are Esri US list prices per user per year, read 23 Nov 2026: Viewer $125, Contributor $250, Mobile Worker $400, Creator $700, Professional $2,200, Professional Plus $4,200, with 0, 250, 250, 500, 500, and 500 credits included. Every rate is editable on the page.
- ArcGIS Enterprise uses the same user type names (Viewer, Editor, Mobile Worker, Creator, GIS Professional Basic, Standard, Advanced) and is priced through the Enterprise Agreement, so the counts in the plan are the numbers to take to your Esri representative.

## Run it

Open `index.html` in any browser. No backend, no API key, no account. Nothing you type is sent or stored anywhere. Print gives a clean summary.
