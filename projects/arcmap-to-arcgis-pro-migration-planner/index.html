ArcMap to ArcGIS Pro Migration Planner

ArcMap retired on March 1, 2026, and the maps, scripts, and custom tools built on it did not retire with it. Count what you have, price the move, and plan it before the renewal date does it for you. Enter your ArcMap estate below and this planner builds a phased migration plan with a person-day estimate, the compatibility flags that set the schedule, and a checklist you can print.

How this planner works, honestly: it runs entirely in your browser. There is no server, no API key, no account, and nothing you enter leaves this page. The compatibility rules come from Esri’s published migration guidance, checked 25 November 2026. The effort numbers are planning ranges from typical migration work, not a quote and not Esri’s numbers, so treat them as the size of the job, not the price of it.
