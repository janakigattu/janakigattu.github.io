AI Agent Eval Harness

A pilot that impresses five people can still fail the sixth question. This harness runs twelve tests against a sample assistant and grades it, so you find the failures before your users do.

Runs entirely in your browser. No backend, no API key, no account. The three assistants and their answers are sample data, built to show three different failure modes: one grounded, one confident and wrong, one loose with what it should refuse. The checks are real: every test compares the answer against the expected facts, the forbidden words, or a numeric limit, and the score is computed live. A production version runs your own test set against your own assistant. Nothing you click is sent anywhere.

What a production version adds

  1. Your own test set. The twelve tests here are samples. A production harness runs the questions your users actually ask, with the expected answers written by your own reviewers.
  2. Graded answers, not just pass or fail. Partial credit for an answer that is right but missing the citation, and a human review queue for the borderline ones.
  3. A run on every release. The harness runs again whenever the assistant, the model, or the documents change, so a regression is caught in the test run, not in production.
  4. Trend over time. The score by category, release after release, shows whether the assistant is getting better or quietly getting worse.
  5. A cost ceiling that bites. The cost and speed tests become a budget: if a release pushes the cost per thousand runs past the limit, the release does not ship.
