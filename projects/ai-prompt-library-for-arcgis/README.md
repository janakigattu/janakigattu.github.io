# AI Prompt Library for ArcGIS

An AI assistant is only as good as the prompt you give it. Twelve prompts, each written for the right ArcGIS assistant, with the blanks filled in and the check named.

## What it does

Pick a task, fill in the blanks, and the prompt updates as you type. Copy it, paste it into the assistant, and run the check at the bottom of the card before you trust the answer.

- **12 prompts** in 5 categories: Create, Analyse, Write code, Describe, Plan.
- **Each prompt names its assistant**, its availability (Generally available at no extra cost, or Beta / preview), and where it runs (ArcGIS Online, or Enterprise 12.0 only for Item details).
- **Where no dedicated assistant is named, it says so.** Three prompts (migration scope, dashboard analysis, workflow handover) name the closest honest option instead of inventing an assistant.
- **Live fill-ins:** every prompt has 2 to 4 fields with sensible defaults. Typing updates the prompt and the copied text.
- **Copy button** on every card, with a clipboard fallback.
- **Four rules for a prompt that works**, and the facts that decide which assistant to switch on first.

## Facts it stands on

- 12 AI assistants live inside ArcGIS. 3 are generally available at no extra cost: Survey123, Business Analyst, Translation. The rest are beta or preview, including Pro, Notebooks, and Arcade.
- Item details is the only assistant in Enterprise, and only in 12.0.
- An administrator must opt in to AI features before a team can use any of them.
- Source: Esri, "What's new in AI assistants" (June 2026): https://www.esri.com/arcgis-blog/products/arcgis-online/geoai/whats-new-in-ai-assistants-june-2026
- Related tools on this portfolio: the AI Assistants in GIS Advisor (which assistant for which task) and the AI Readiness Assessment (whether the team is ready before spending anything).

## How to run it

Open `index.html` in any browser. No server, no API key, no account. Nothing you type leaves the page.
