AI Prompt Library for ArcGIS

An AI assistant is only as good as the prompt you give it. Twelve prompts, each written for the right ArcGIS assistant, with the blanks filled in and the check named.

How this library works, honestly: it runs entirely in your browser. There is no server, no API key, no account, and nothing you type leaves this page. The prompts are templates. The assistant does the work inside ArcGIS. Availability comes from Esri’s public update on AI assistants, and where no dedicated assistant is named, this library says so instead of inventing one.

Four rules for a prompt that works

1. Name the data

A prompt that names the layer, the fields, and the question gets a useful answer. A prompt that says “analyse this” gets a guess.

2. Name the output

Say what you want back: a table, an expression, a summary under 120 words. If you do not name it, the assistant picks for you.

3. Name the check

Every prompt below ends with a check. Run it. The assistant drafts, a human approves.

4. Keep a human in the loop

Nothing here goes live without a person reading it first. That is the rule that keeps an assistant useful instead of risky.

What the assistants can and cannot do

12 AI assistants live inside ArcGIS.
3 are generally available at no extra cost: Survey123, Business Analyst, Translation.
The rest are beta or preview, including Pro, Notebooks, and Arcade.
Item details is the only one in Enterprise, and only in 12.0.
An administrator must opt in before your team can use any of them.

Browse the prompts

Fill in the blanks and the prompt updates as you type. Copy it, paste it into the assistant, and run the check at the bottom of the card.
