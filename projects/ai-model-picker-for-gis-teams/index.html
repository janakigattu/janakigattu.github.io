How the pick is made

  1. The task sets the starting tier. Drafting and translation start at Lightweight. Summarising, code, image analysis, and extraction start at Balanced, because long context and structured output reward the stronger model.
  2. Must be right every time moves the pick up one tier. When the answer cannot be wrong, pay for the stronger model and still have a person check it.
  3. Seconds matter moves the pick down one tier. The lightweight model answers fastest. If accuracy and speed pull in opposite directions, accuracy wins and the pick stays where the task put it.
  4. Data sensitivity never changes the model pick. It changes how the data reaches the model: redact it, or keep it inside an approved tool.
  5. The cost is the proof. Every tier is priced on the same volume, so you can see what the stronger model actually costs you per month.
